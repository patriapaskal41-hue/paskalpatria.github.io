Mengenal HTML untuk Pemula

Belajar HTML dari dasar, lengkap dengan materi, contoh kode, dan penjelasannya.

Home Artikel Kategori

1. Apa Itu HTML?

HTML adalah singkatan dari HyperText Markup Language. HTML digunakan untuk membuat struktur halaman website, seperti judul, paragraf, gambar, tautan, dan formulir.

Contoh Kode

<h1>Halo, PatriaTech!</h1>
<p>Saya sedang belajar HTML.</p>

Penjelasan

  • <h1> untuk membuat judul utama.
  • <p> untuk membuat paragraf.

2. Struktur Dasar HTML

Setiap halaman HTML memiliki struktur dasar yang digunakan browser untuk membaca dokumen.

Contoh Kode

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Website Pertama</title>
</head>
<body>
    <h1>Selamat Datang</h1>
    <p>Ini website pertama saya.</p>
</body>
</html>

Penjelasan

  • <!DOCTYPE html> menandakan dokumen HTML modern.
  • <html> merupakan elemen utama HTML.
  • <head> berisi informasi halaman.
  • <title> menentukan judul tab browser.
  • <body> berisi konten halaman.

3. Heading dan Paragraf

Heading digunakan untuk judul dan subjudul. HTML memiliki enam tingkat heading, yaitu <h1> sampai <h6>.

Contoh Kode

<h1>Belajar HTML</h1>
<h2>Materi Dasar</h2>
<h3>Pengertian HTML</h3>

<p>HTML digunakan untuk membuat struktur website.</p>

Penjelasan

Tag <h1> digunakan untuk judul utama, sedangkan <h2> dan <h3> digunakan untuk subjudul. Tag <p> digunakan untuk paragraf.

4. Membuat Link

Link atau tautan digunakan untuk mengarahkan pengunjung ke halaman lain atau website tertentu.

Contoh Kode

<a href="https://example.com">
    Kunjungi Website
</a>

Penjelasan

Tag <a> membuat tautan. Atribut href menentukan alamat tujuan tautan.

5. Menampilkan Gambar

HTML menyediakan tag <img> untuk menampilkan gambar pada halaman website.

Contoh Kode

<img
    src="gambar.jpg"
    alt="Gambar pemandangan"
    width="300"
>

Penjelasan

  • src menentukan lokasi file gambar.
  • alt memberikan teks alternatif gambar.
  • width menentukan lebar gambar.

Pastikan file gambar.jpg tersedia di lokasi yang sesuai.

6. Membuat Daftar

HTML memiliki daftar berpoin dan daftar bernomor.

Contoh Kode

<h3>Bahasa Website</h3>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<ol>
    <li>Belajar HTML</li>
    <li>Belajar CSS</li>
    <li>Belajar JavaScript</li>
</ol>

Penjelasan

  • <ul> membuat daftar berpoin.
  • <ol> membuat daftar bernomor.
  • <li> membuat setiap item daftar.

7. Membuat Tabel

Tabel digunakan untuk menyusun data dalam baris dan kolom.

Contoh Kode

<table border="1">
    <tr>
        <th>Nama</th>
        <th>Umur</th>
    </tr>

    <tr>
        <td>Patria</td>
        <td>18</td>
    </tr>
</table>

Penjelasan

  • <table> membuat tabel.
  • <tr> membuat baris.
  • <th> membuat sel judul.
  • <td> membuat sel data.

8. Membuat Formulir

Formulir digunakan untuk menerima masukan dari pengunjung website.

Contoh Kode

<form>
    <label for="nama">Nama:</label>

    <input
        type="text"
        id="nama"
        name="nama"
        placeholder="Masukkan nama"
    >

    <button type="submit">Kirim</button>
</form>

Penjelasan

  • <form> menjadi wadah formulir.
  • <label> memberikan keterangan input.
  • <input> menerima masukan.
  • <button> membuat tombol.

9. Mengenal Atribut HTML

Atribut memberikan informasi tambahan pada sebuah elemen HTML.

Contoh Kode

<input
    type="text"
    placeholder="Tulis nama kamu"
>

<a href="https://example.com">
    Buka Website
</a>

Penjelasan

  • type menentukan jenis input.
  • placeholder menampilkan petunjuk.
  • href menentukan alamat tautan.

10. Membuat Website Sederhana

Sekarang gabungkan beberapa elemen HTML untuk membuat halaman website sederhana.

Contoh Kode Lengkap

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Website Pertamaku</title>
</head>

<body>
    <header>
        <h1>Selamat Datang</h1>
        <p>Ini website pertamaku.</p>
    </header>

    <main>
        <h2>Tentang Saya</h2>
        <p>Saya sedang belajar membuat website.</p>

        <a href="https://example.com">
            Contoh Link
        </a>
    </main>

    <footer>
        <p>Website dibuat untuk belajar HTML.</p>
    </footer>
</body>
</html>

Penjelasan

Contoh ini menggunakan heading, paragraf, tautan, serta elemen semantik seperti <header>, <main>, dan <footer>.

Kesimpulan

HTML digunakan untuk membangun struktur halaman website. Setelah memahami HTML, kamu bisa melanjutkan belajar CSS untuk mempercantik tampilan dan JavaScript untuk menambahkan interaksi.
